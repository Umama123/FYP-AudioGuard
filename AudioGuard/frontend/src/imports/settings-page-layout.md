Settings Page Layout

The page title at the top should be:

Settings

Below the title create vertically stacked glassmorphism cards with 32px spacing between them.

1️⃣ Profile Settings Card

Title: Profile Settings

Description: Manage your account information.

Layout:

Left side:
Profile avatar (circular)

Right side editable fields:

Profile Picture Upload
Full Name
Email Address
Organization / Company
Role (Admin / Analyst / User)

Buttons:

Edit Profile (secondary button)
Save Changes (primary purple gradient button)

2️⃣ Security Settings Card

Title: Security Settings

Include the following options:

Change Password button

Two-Factor Authentication
Toggle switch: Enable / Disable

Login Alerts
Toggle switch

Login Activity History
Link button: View History

Active Sessions
Button: Logout from other devices

Include security icons and status indicators.

3️⃣ Audio Processing Preferences Card

Title: Audio Processing Preferences

Controls for how AI processes audio.

Include dropdowns:

Default Detection Mode
Options:
Fast
Balanced
High Accuracy

Enhancement Quality
Options:
Standard
Enhanced
Studio Quality

Include toggles:

Noise Reduction
Auto Normalize Volume

Show small AI or waveform icons for this section.

4️⃣ Notification Settings Card

Title: Notification Settings

Display a list with toggle switches:

Email Notifications
Detection Result Alerts
System Updates
Security Alerts
Weekly Analytics Report

Example toggle layout:

Deepfake Detection Alerts - ON
Security Notifications - ON
Weekly Report - OFF

5️⃣ Data & Privacy Card

Title: Data & Privacy

Include dropdown:

Auto Delete Audio Files after:
7 Days
30 Days
Never

Toggle:

Allow Audio Storage for Model Improvement

Buttons:

Export My Data
Delete Account (danger button in red)

Add a warning style box around destructive actions.

6️⃣ System Preferences Card

Title: System Preferences

Options:

Theme
Light Mode
Dark Mode

Language dropdown

Dashboard Layout Density
Compact
Comfortable

7️⃣ API Integration Card

Title: API & Integrations

Include:

API Key Generation button
Webhook URL input field
External integrations list

Show integration icons.

UI Style Requirements

Use modern SaaS design principles:

Glassmorphism cards with subtle blur
Soft shadows and clean spacing
Purple gradient buttons
Smooth hover animations
Interactive toggle switches
Minimal line icons

Spacing between cards: 32px

Use Auto Layout for responsiveness.

Interaction & Prototype

Add interactive states:

Button hover animation
Toggle ON/OFF animation
Smooth transitions between sections using Smart Animate

Design Goal

The final screen should look like a professional AI cybersecurity SaaS dashboard settings page, consistent with the AudioGuard dashboard, Audio Detection, and Audio Enhancement modules.

It should feel modern, minimal, secure, and high-tech.
